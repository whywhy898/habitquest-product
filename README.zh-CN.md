# HabitQuest

**一个游戏化的家庭习惯与零花钱协作中心，把日常事务转化为任务、奖励和共同成长。**

[English](README.md) · [官方网站](https://habitquests.org/) · [联系邮箱](mailto:contact@habitquests.org)

> **当前阶段：** 可运行 MVP · 持续开发中 · 独立创始人主导

## 产品简介

HabitQuest 让家庭日常事务更清晰、更有参与感。孩子可以查看任务与成长进度，家长则负责审核完成情况、设置计划并管理奖励。

## 当前 MVP 已支持

- **日常任务**：创建清晰、可重复的家庭任务。
- **家长管理**：审核任务完成情况、安排计划并保持适龄体验。
- **家庭奖励体系**：将成长进度与家长管理的虚拟或现实奖励连接起来。
- **成长回顾**：基于记录的活动生成有依据的每周成长洞察。
